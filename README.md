# سیگارشمار (PWA آفلاین)

یک اپلیکیشن وب (PWA) برای ثبت خرید و مصرف سیگار، با تقویم و ساعت شمسی، کاملاً آفلاین و قابل نصب روی گوشی.

## قابلیت‌ها
- ثبت خرید پاکت سیگار (۲۰ نخ) همراه با قیمت
- ثبت هر نخ سیگاری که کشیده‌اید (از موجودی خودتان)
- ثبت نخ سیگار قرضی که کشیده‌اید (روی موجودی شما تأثیری ندارد)
- ثبت نخ سیگاری که به کسی قرض داده‌اید (از موجودی شما کم می‌شود)
- نمایش موجودی فعلی سیگار
- جدول آمار روزانه (شمسی) با مشخص‌شدن روزهای پرمصرف‌ترین و کم‌مصرف‌ترین
- تاریخچهٔ کامل رویدادها با امکان حذف
- کارکرد کامل آفلاین (Service Worker) و ذخیرهٔ اطلاعات با IndexedDB
- قابل نصب روی صفحهٔ اصلی گوشی (Add to Home Screen)

## دربارهٔ محل ذخیرهٔ اطلاعات
مرورگرها (به‌خصوص در گوشی) اجازه نمی‌دهند یک برنامهٔ وب مسیر دلخواه روی حافظهٔ گوشی را برای ذخیره‌سازی انتخاب کند؛ این یک محدودیت امنیتی مرورگر است، نه محدودیت این برنامه. به‌جای آن، از **IndexedDB** استفاده شده که حافظهٔ داخلیِ خودِ همین برنامه است و:
- با رفرش‌کردن، بستن تب، یا بستن برنامهٔ نصب‌شده پاک نمی‌شود.
- فقط برای همین برنامه قابل‌دسترسی است (نه بقیهٔ سایت‌ها).
- بار اول اجرا، برنامه یک‌بار از مرورگر اجازهٔ «دائمی‌شدن» حافظه را می‌گیرد (`navigator.storage.persist`) تا سیستم‌عامل آن را در کمبود فضا پاک نکند؛ از دفعهٔ بعد دیگر چیزی پرسیده نمی‌شود.
- تنها راه پاک شدن اطلاعات: دکمهٔ «پاک کردن کامل اطلاعات» در تنظیمات، یا پاک‌کردن دستی «Site data» همان برنامه از تنظیمات مرورگر/گوشی.

## راه‌اندازی روی GitHub Pages

1. یک ریپازیتوری تازه در گیت‌هاب بسازید (مثلاً `cig-tracker`).
2. تمام فایل‌ها (همگی داخل یک پوشه، بدون زیرپوشه) را در ریشهٔ همان ریپازیتوری آپلود/پوش کنید: `index.html`, `manifest.json`, `sw.js`, `style.css`, `app.js`, `db.js`, `jalali.js`, `icon-192.png`, `icon-512.png`, `icon-180-maskable.png`
   ```bash
   git init
   git add .
   git commit -m "cigarette tracker pwa"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
3. در گیت‌هاب: Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main** / **root** → Save.
4. بعد از چند دقیقه آدرس شما در دسترس است:
   `https://USERNAME.github.io/REPO/`
5. همین آدرس را در گوشی (کروم/سافاری) باز کنید و از منوی مرورگر گزینهٔ **Add to Home screen** / **نصب برنامه** را بزنید.

> نکته: چون آدرس گیت‌هاب پیجز داخل یک زیرمسیر (`/REPO/`) است، تمام مسیرهای داخل پروژه به‌صورت نسبی (`./`) نوشته شده‌اند تا مشکلی پیش نیاید.

## تست محلی قبل از انتشار
چون Service Worker نیاز به HTTPS یا localhost دارد، فایل را مستقیم دابل‌کلیک نکنید؛ به‌جایش یک سرور سادهٔ محلی اجرا کنید:
```bash
python3 -m http.server 8080
```
و آدرس `http://localhost:8080` را باز کنید.

## به‌روزرسانی بعدی
هر بار کدها را تغییر دادید، مقدار `CACHE_NAME` در `sw.js` را عوض کنید (مثلاً `cigtrack-v2`) تا کاربران نسخهٔ جدید را دریافت کنند.
